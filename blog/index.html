    The Kalman Filter Is Natural Gradient Descent

    Two communities wrote down the same algorithm forty years apart and didn't notice. Estimation theory called it the Kalman filter in 1960. Machine learning called it natural gradient in the 1990s. The equivalence is exact — and it changes how you read every modern second-order optimizer.
