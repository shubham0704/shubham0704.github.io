What happens if the robot chooses a different future?

C-PHAST starts from one observed state and a finite candidate set. It rolls every candidate forward and returns named consequences before an objective turns them into a ranking or veto.

What does a candidate query return?

Observe state x̂t = Observeθ(h, S)
Configure candidate rollout Sk = Activate(S, ak, x̂t) Builds hypothetical controls, ports, contacts, and interconnection; no robot command is sent.
Roll out x̂t:t+H(k) = CPHASTθ(x̂t, ak, Sk)
Read consequences ρ(k) = [OpH(x̂), Olearned,θ(x̂, Sk)]
Build factors φ(k) = Factors(ρ(k), h, ak, Sk)
Rank or veto sk = wTφ(k),   gj(φ(k)) ≤ 0

CPHASTθ is the dynamics model; OpH and Olearned,θ are post-rollout readout operators. The factor map uses declared horizon aggregation and fixed training-split calibration; objectives supply weights and hard envelopes.

Why compose instead of learning one monolithic model?

A monolithic model learns local component behavior and one system layout as a single object. C-PHAST learns each repeated physical type once, then instantiates the shared blocks under the target component count, topology, contacts, and observation interface.

Changing interconnection topology

Microgrid problem Train shared DGU and line blocks on a three-DGU source graph; query added/removed DGUs, feeder rewiring, and voltage-only sensing without retraining the local blocks.
Physical block state qi = CiVi, pi = Lt,iIt,i; the supplied incidence matrix Binc connects DGU nodes to line edges.
Model-training objective The voltage-only tier also trains its observer on hidden-state and next-voltage error. Evaluation reports bus-voltage and line-current rollouts, voltage balancing, current sharing, energy change, and typed mismatch residuals.

Why port-Hamiltonian composition? Skew port coupling contributes zero net internal power, so rewiring preserves the blocks' local storage, dissipation, and power accounting.

Controller boundary. Converter voltages and load currents are supplied inputs. The reported study evaluates a reconfigurable forecasting surrogate for regulation and protection; it does not learn the DGU controller.
