Compositional port-Hamiltonian world models

Compare physical futures before choosing an action.

C-PHAST learns reusable physics blocks, recomposes them for a target deployment, and turns candidate rollouts into named physical consequences.

The model does not emit one opaque score. It predicts quantities a planner can reason about: energy use, support/contact margin, sensing value, voltage or current margin, and residual mismatch.

What the model exposes

From observables to action cards.

A typed consequence is a named physical quantity with a role: reward, cost, safety envelope, or residual check. Objective cards reuse the same predicted consequences, then change weights or veto rules.

1

Observe

Recent robot, circuit, or grid measurements refresh the deployed state.

2

Roll out

Candidate futures are simulated with the target blocks, graph, ports, and sensing interface.

3

Name the consequences

Rollouts become physical readouts such as work, support margin, map value, voltage margin, or residual mismatch.

4

Choose by objective

Downstream objectives turn the same consequence vector into action cards, rankings, or vetoes.

Real robot evidence

Spot-with-arm logs test the telemetry-to-card path.

Six teleoperated Spot-with-arm episodes are replayed offline. C-PHAST reads recent telemetry and synchronized perception summaries, predicts named future consequences for a possible next behavior, and writes objective-conditioned action cards beside the logged run.

This is shadow mode: no autonomous commands are sent to Spot. The result validates the real sensing and decision interface, while the Isaac experiments below validate branchable same-state alternatives in simulation.

Branchable rollout evidence

Simulation asks the counterfactual question.

Real logs show whether the interface works on hardware data. Simulator rollouts let us hold the state fixed and ask what would happen under alternative candidate futures.

Same contract, different physics

Transfer is expressed in each domain's own language.

C-PHAST is not a single robot trick. The same contract appears as repeated joint or leg blocks, repeated excitable cells, and typed converter-line blocks in a power network.

Legged robots

Reusable mechanical blocks are recomposed for a target embodiment and support/contact pattern.

Repeated excitable cells

FitzHugh-Nagumo chains test whether repeated cell blocks transfer under changes in cell count and diffusive graph.

DC microgrids

DGU node blocks and line edge blocks are recomposed under topology and sensing changes.

Model contract

Reusable blocks, deployment-specific wiring.

The method separates local physics from the way a target system is assembled. This is why the paper can compare subsystem-count changes, cross-robot transfer, repeated excitable circuits, and microgrid topology or sensing changes under one interface.

  • Local blocks store and dissipate energy.
  • Ports describe how power enters, leaves, or moves between blocks.
  • Interconnections wire the deployed system without changing the learned local library.
  • Typed readouts expose what a planner or operator needs to compare futures.
